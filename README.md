# VisionDetect-AI

## AI-Powered Object Detection Using Deep Learning

VisionDetect-AI is a web-based object detection application built using Python, TensorFlow, and Flask. It allows users to upload an image and detect objects using a pre-trained deep learning model.


## ✨ Features

- 📤 Upload images through a simple web interface

- 🧠 Detect objects using a pre-trained TensorFlow model

- 🏷️ Display detected object labels and confidence scores

- 🖼️ View the processed image with detection boxes

- 🌐 User-friendly web interface built with Flask, HTML, and CSS



## 🛠️ Technologies Used

- Python

- TensorFlow

- Flask

- NumPy

- HTML

- CSS

- Git and GitHub


## 📂 Project Structure

app.py — Main Flask application

templates/ — HTML templates for the web interface

static/ — CSS styling files

object_detection_saved/ — Pre-trained model files stored locally

README.md — Project documentation


## 🎯 Project Objective

The goal of VisionDetect-AI is to demonstrate how deep learning and computer vision can be integrated into a web application to identify objects in uploaded images.


## 🚀 Applications

- Image analysis

- Computer vision demonstrations

- Object recognition systems

- AI-powered image processing


## ⚙️ How It Works

- Upload an image.

- The deep learning model analyzes it.

- Detected objects and confidence scores are displayed.

- Bounding boxes highlight the detected objects.


## 🎯 Objective

To integrate deep learning and computer vision into a user-friendly web application for image-based object detection.
